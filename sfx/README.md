# Hit sounds

Recorded punches and impacts from "37 hits/punches" by Independent.nu on OpenGameArt
(https://opengameart.org/content/37-hitspunches), released under CC0 (public domain, no credit required).

Changes: thirteen were picked, the silence at the start was trimmed, levels were evened out, and they were converted to AAC.
The game falls back to its own generated sounds if these files are missing.
